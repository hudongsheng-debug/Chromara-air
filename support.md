## Quick start
- Choose the built-in example or open a FITS/image file.
- Edit color stops, display curves, and black/white levels.
- Switch grayscale/color preview to inspect the result.
- Save a local project or export a palette package or PNG.

## Data and scope
FITS support is for uncompressed 2D primary images or IMAGE extensions, not compressed FITS or cubes. Editing previews and PNG exports have a maximum long edge of 1024 pixels. Projects retain preview sessions and display parameters, not a complete FITS backup. Color mapping does not alter the original file.

## Saving and backups
Project thumbnails, preview pixels, display ranges, color parameters, and user presets are stored locally in the app. Original FITS files are not kept as complete backups; export important palette packages and PNGs yourself.
Export important work and retain source files before offloading or deleting the app. Offload App and Delete App can have different effects; check the actual system option on your iPad.

## Frequently asked questions

### Why is the export not full resolution?
This version edits and exports a preview with a maximum long edge of 1024 pixels. The original file is unchanged.

### Does saving a project back up the original FITS file?
No. A project retains preview pixels and display parameters. Keep the original file separately.

### A file is missing from the picker, or a cloud file will not open
In Files, confirm the file is fully downloaded, accessible, and in a supported format. Try a local copy under On My iPad. A matching filename extension does not guarantee a supported internal structure.

### How should I report a problem?
Describe the action, expected result, and actual result, with screenshots free of sensitive information. If an example is needed, prefer a small synthetic file. You may report the problem without a source file first; we can follow up from your description.

## Privacy
No account is required and core processing takes place on your device. Read the privacy policy in this folder for local storage, file services, and voluntary support communications.
